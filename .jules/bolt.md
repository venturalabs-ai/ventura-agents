## 2024-06-25 - Avoid spreading Map/Set iterables for functional methods in TypeScript
**Learning:** Found an anti-pattern in the codebase where Map/Set iterables are spread into arrays (e.g. `[...map.values()].filter(...)`) to use array functional methods. This is an O(N) memory overhead because it allocates an intermediate array, and iterating directly over iterables using a `for...of` loop is more efficient. Also learned that when refactoring this, avoid strictly checking for native `Promise`s before passing results to `Promise.all()` as `Promise.all()` will automatically handle mixed arrays.
**Action:** Always use a direct `for...of` loop over Map and Set iterables, populating a result array directly instead of spreading into an array and executing functional methods like `.map()` or `.filter()`.
