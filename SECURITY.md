# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | ✅ Yes             |
| < 3.0   | ❌ No              |

## Reporting a Vulnerability

If you discover a security vulnerability in the Ventura Agents Ecosystem, please report it responsibly.

**Do not open public GitHub issues for security reports.**

### How to report

1. Email: **security@venturalabs.ai** (preferred)
2. Or contact the repository owner directly via the GitHub private security advisory feature.

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)
- Your contact information for follow-up

### Response timeline

- We will acknowledge receipt within **48 hours**
- We aim to provide an initial assessment within **5 business days**
- Critical issues will be prioritized and patched as quickly as possible

### Safe Harbor

We support responsible disclosure. Researchers acting in good faith will not face legal action from Ventura Labs AI for reports submitted according to this policy.

Thank you for helping keep the Ventura Agents Ecosystem secure.
